# Project Statement – 1

## Project Objective

The objective of this project is to enable students to apply their knowledge of HTML and basic CSS styling to create a structured and visually appealing personal profile webpage.

## Project Information

- **Project Title:** Personal Portfolio Webpage
- **Difficulty Level:** Beginner
- **Dataset Source:** Self-Created Content
- **Primary Skills:** HTML, CSS (Basic + Positioning), Git

### Problem Description

Create a personal portfolio webpage that includes sections like About Me, Skills, Projects, and Contact Information using HTML and CSS.

### Required Steps

1. Create HTML structure.
2. Add headings, paragraphs, and images.
3. Style using basic CSS.
4. Use CSS positioning for layout.
5. Add navigation menu.
6. Improve typography.
7. Add footer.
8. Test responsiveness.
9. Optimize layout.
10. Deploy locally and manage via Git.

## Project Execution Workflow

### Phase 1 – Problem Understanding
- Understand portfolio structure.
- Identify sections.
- Define output.

### Phase 2 – Design
- Plan layout.
- Choose colors.
- Define sections.

### Phase 3 – Development
- Create HTML structure.
- Apply CSS styling.

### Phase 4 – Version Control
- Initialize Git.
- Commit changes.
- Push to repository.

### Phase 5 – Testing
- Check layout.
- Fix issues.

### Phase 6 – Final Output
- Clean UI.
- Organized code.
